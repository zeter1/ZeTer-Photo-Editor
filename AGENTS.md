# ZeTer Photo Editor

Рабочие правила и карта проекта находятся в [docs/PROJECT.md](docs/PROJECT.md).

- Исходники runtime: `src/core/*.js` и `src/main.js`; `src/app.bundle.js` генерируется командой `npm run build` и вручную не редактируется.
- Приложение должно продолжать работать при прямом открытии `index.html` через `file://` на Windows.
- Любое растровое изменение должно учитывать блокировку слоя, активное выделение, Undo/Redo и асинхронное сохранение Canvas.
- После изменения исходников запускать `npm run check`; живое поведение Canvas и расположение интерфейса дополнительно проверять в браузере.
- Принятые изменения записывать одним фактическим блоком в корневой `CHANGELOG.md`.
