# ZeTer Photo Editor — быстрый инженерный вход

ZeTer Photo Editor — локальный браузерный многослойный растровый редактор. Обычная работа не требует сервера; production/runtime contract включает прямое открытие `index.html` через `file://`.

> Цель этого файла — дать разработчику или AI достаточную карту за несколько минут. Детальные исторические заметки вынесены в [reference/PROJECT_HISTORY.md](reference/PROJECT_HISTORY.md).

## 2. Source of truth

- `src/main.js` — runtime orchestrator и владелец tool-specific pointer/keyboard dispatch. Это всё ещё большой файл; не читай его целиком без необходимости. Ищи конкретный symbol/event handler.
- `src/interaction/pointer-lifecycle-router.js` — generic lifecycle overlay-pointer: один active pointer, capture/release, фильтрация чужих move/up/cancel и fail-safe отмена при `lostpointercapture`; не знает про move/paint/crop/path semantics.
- `src/ui/tool-config.js` — чистые UI-константы, labels/help/effect-control metadata/storage keys.
- `src/ui/toolbar-controller.js` — drag/drop/persistence/drop-slot и rich tooltip lifecycle панели инструментов; выбор текущего tool остаётся в `src/main.js`.
- `src/ui/menu-controller.js` — lifecycle верхнего меню и context-menu: DOM items, позиционирование, focus/keyboard navigation, outside-click close и безопасный async action dispatch; доменные списки команд остаются в `src/main.js`.
- `src/ui/modal-controller.js` — generic modal/dialog shell: form fields, numeric normalization, focus restore, backdrop/Escape close, draggable text-modal lifecycle, info dialogs и recovery project-manager dialog; feature-specific state не хранит и получает только узкие callbacks.
- `src/ui/text-edit-controller.js` — Text add/edit transaction owner: exact target guards, transient draft, latest-wins async preview и preview-canvas lifecycle.
- `src/ui/text-settings-controller.js` — shared Text typography/font UI-policy owner: option sets, local-font discovery/private registry, custom-font cache/validation, modal fields и form normalization. Properties использует его через narrow methods; DOM/markup остаются в `src/main.js`, а generic property mutation/history publication делегируются `src/layers/property-command-controller.js`.
- `src/ui/workspace-layout-controller.js` — shell-layout owner: persisted collapse state sidebar-карточек, legacy migration, ARIA/title update и canvas mode hide/show с сохранением canvas point в центре viewport; не владеет document/layer state.
- `src/ui/layers-panel-controller.js` — owner DOM/presentation lifecycle панели Layers: recursive tree ordering, selected/effective visibility-lock presentation, thumbnails/mask hints, row-local keyboard focus и layer/group DnD including root drop. Он хранит drag identity локально и отбрасывает callbacks от уже неактивного document; semantic mutation/history policy не дублируется: panel вызывает `src/layers/command-controller.js` через explicit action ports.
- `src/layers/command-controller.js` — canonical primitive layer/group command owner: exact active-document + entity re-resolution, recursive lock guards, stale modal Apply rejection, no-op history suppression, create/rename/delete/visibility/lock/group-properties and layer/group move publication. Stable document mutations remain in `src/core/state.js`; `src/main.js` only supplies live transaction/modal/status ports and feature-heavy menu composition.
- `src/layers/transform-command-controller.js` — canonical one-shot selected-layer layout transform owner for nudge/center/align/fit: re-resolves the active target by ID, rejects recursive locks and non-transformable Adjustment layers, uses core frame geometry, suppresses semantic no-ops and publishes exactly one history entry for a real transform. Pointer Move/Resize/Rotate gestures and Properties live preview remain outside this owner.
- `src/interaction/layer-transform-surface-controller.js` — canonical read-only selected-layer transform surface: transformable/visible/recursive-lock policy, selected-control rotate/resize hit classification, topmost Move targeting, frame/handles/rotation/name-badge drawing and rotated idle cursors. It emits semantic pointer intent only; mutation/history/Smart Snap/rollback remain in `src/interaction/layer-transform-gesture-controller.js`, discrete commands in `src/layers/transform-command-controller.js`, and pointer dispatch/DOM cursor application in `src/main.js`.
- `src/interaction/path-control-surface-controller.js` — canonical read-only surface owner for existing Bézier controls across Shape paths, Vector Masks and Saved Paths: edit-target precedence, visibility/lock presentation policy, layer→document projection, handle-before-anchor hit-testing, zoom-stable overlay drawing/path tracing and idle Pen cursor feedback. It may clear an invalid transient Saved Path edit index, but owns no persisted path mutation/history; one-shot corner conversion belongs to `src/interaction/path-control-command-controller.js`, drag transactions to `src/interaction/path-control-gesture-controller.js`, and transient new-path draft/handle creation lives in `src/interaction/pen-draft-gesture-controller.js`, while final persisted publication belongs to `src/interaction/pen-path-command-controller.js`.
- `src/interaction/path-control-command-controller.js` — canonical one-shot persisted command owner for Alt-clicking an existing anchor into corner semantics across Shape paths, Vector Masks and Saved Paths. It accepts only anchor+Alt intent, revalidates the active document, resolves the exact live target through the surface port, rechecks recursive lock state immediately before mutation, clears both handles, suppresses history on the already-corner semantic no-op, preserves exact source-specific history labels and reports the existing no-op status. It does not discover/draw controls, own drag state or create new Pen paths.
- `src/interaction/path-control-gesture-controller.js` — canonical transaction owner for dragging existing Bézier anchors/handles across Shape paths, Vector Masks and Saved Paths: captures the originating document plus exact layer/path/subpath/node identity, uses stable Saved Path IDs when available, enforces recursive locks, document↔layer coordinates, zoom threshold rollback, final-release geometry, semantic no-op suppression, exact history labels and shared cancel/Escape rollback. Target discovery/projection/hit-testing/control drawing/cursor feedback belong to `src/interaction/path-control-surface-controller.js`; Alt-click corner conversion belongs to `src/interaction/path-control-command-controller.js`; transient new-path draft/handle creation lives in `src/interaction/pen-draft-gesture-controller.js`, while final persisted publication belongs to `src/interaction/pen-path-command-controller.js`.
- `src/layers/property-command-controller.js` — canonical generic layer-property command owner: exact document/layer re-resolution, recursive lock guard, numeric/text/filter/HDR normalization, canvas-size safety, no-op suppression, live-preview baseline tracking and one final history publication for Properties ranges, discrete Image-menu filter resets, persistent layer opacity/blend and HDR display controls. Properties markup stays in `src/main.js`; core sanitizers stay in `src/core/state.js`; specialized Adjustment/Blending/Smart Filter/Text owners remain separate.
- `src/layers/adjustment-command-controller.js` — canonical persisted Adjustment Layer command owner: scalar/Levels paths, Curves point parsing/replacement and clipping toggle re-resolve the originating document + stable layer ID, honor recursive locks, sanitize through `src/core/adjustments.js`, suppress semantic no-op history and publish each real command once. Properties markup remains in `src/main.js`; Photoshop-native metadata planning remains in document/PSD modules.
- `src/interaction/pen-draft-gesture-controller.js` — canonical transient owner for creating a new Pen path before persistence: owns draft points/hover, `4 / zoom` finish intent, `1 / zoom` point-handle drag threshold, smooth mirrored vs Alt-independent handles, final-release geometry, exact release statuses, exact transient-node cancel, full-draft reset and immutable snapshots. It publishes no layer/history; finalized bounds/localization/Shape publication belongs to `src/interaction/pen-path-command-controller.js`.
- `src/interaction/pen-path-command-controller.js` — canonical one-shot persisted owner for a consumed new-Pen draft: exact active-document guard + pre-write revalidation, finite anchor/handle validation, handle-inclusive bounds, layer-local projection, canonical Shape-path options, semantic no-op suppression and exactly one `Добавить Bézier-контур` history publication. Pointer/keyboard dispatch and success-status/redraw presentation remain in `src/main.js`.
- `src/ui/paths-controller.js` — Saved Paths orchestration owner: selected path index, Photoshop-compatible resource allocation/limit, CRUD, accessible panel/context-menu wiring и apply-as-vector-mask через grouped injected ports; existing edit-target discovery/projection/hit-testing/control drawing/cursor feedback belongs to `src/interaction/path-control-surface-controller.js`, drag existing anchors/handles belongs to `src/interaction/path-control-gesture-controller.js`, while transient new Pen drafting lives in `src/interaction/pen-draft-gesture-controller.js`, and edit-mode identity/final publication plus the PSD binary codec stay outside.
- `src/ui/color-management-controller.js` — document CMYK/ICC orchestration owner: preview/edit transform caches, policy/profile transactions, async preview rebuild + stale-document rollback и properties-panel bindings. ICC parsing/transform math остаётся в `src/core/color-management.js`; PSD/PSB byte semantics — в `src/formats/psd.js`.
- `src/ui/tool-layout.js` — чистая математика порядка/позиции toolbar.
- `src/workspace/session-controller.js` — lifecycle document sessions: create/switch/close/rename/duplicate, per-tab history/zoom/dirty/selection state и smart-object parent/child tab guard.
- `src/workspace/recovery-controller.js` — application-level recovery owner: per-window key ownership, debounce/write serialization, dirty-session snapshots, startup saved-project listing/restore/delete policy, explicit cross-window delete confirmation and preservation of unreadable sibling snapshots. It receives storage/project/session/UI ports explicitly; IndexedDB records stay in `src/core/recovery.js`.
- `src/selection/gesture-controller.js` — канонический владелец transient selection gesture state: selection type, marquee/lasso drag lifecycle, polygon/magnetic drafts, edge snapping и draft overlay. Generic pointer capture/ownership живёт в `src/interaction/pointer-lifecycle-router.js`; `src/main.js` оставляет tool/keyboard dispatch и canonical selection shape bridge.
- `src/selection/clipboard-controller.js` — selection copy/cut/paste boundary: PNG preparation, system Clipboard API, native paste/fallback generation guards и tab-switch safety; destructive pixel mutation вызывается через отдельный selection raster-mutation callback.
- `src/selection/raster-mutation-controller.js` — владелец destructive selection raster mutations: merged cut по видимым незаблокированным pixel layers, prepare-all-before-mutate, high-depth clear, rasterization non-raster layers и команда rasterize selected layer с document/session stale guard.
- `src/selection/mask-controller.js` — владелец selection → raster-mask / Select & Mask orchestration: mask rasterization for layer/document coordinates, bounded refine preparation, non-destructive modal preview, add/remove/final Apply transactions and exact document + selected-layer + lock revalidation after awaits. `src/core/pixels.js` owns refine math; Smart Filter reuses only `selectionMaskDataUrl()` and keeps its own mutation/publication owner.
- `src/selection/vector-mask-controller.js` — владелец selection → Vector Mask command/policy seam: exact rect/ellipse/path geometry projection, layer-local localization, boolean subpath publication, 128-path guard and mask lifecycle commands. Он вызывает Pen edit только через narrow runtime port; existing target discovery/projection/hit-testing/control drawing/cursor feedback belongs to `src/interaction/path-control-surface-controller.js`, one-shot Alt-click corner conversion belongs to `src/interaction/path-control-command-controller.js`, existing anchor/handle drag transaction belongs to `src/interaction/path-control-gesture-controller.js`, while `vectorMaskEditLayerId` edit identity stays in `src/main.js`, new Pen draft/handle gestures live in `src/interaction/pen-draft-gesture-controller.js`, final Shape/history publication lives in `src/interaction/pen-path-command-controller.js`, and PSD import/export bridges remain outside.
- `src/document/smart-object-controller.js` — Smart Object content/session lifecycle owner: convert/open/save/link/unlink, shared-source propagation, nesting/source-bounds rules и async content-tab stale guards. Browser preview rendering, session/runtime publication и Photoshop embedded-resource rewrite приходят через узкие ports; PSD/PSB bytes остаются вне generic controller.
- `src/document/import-controller.js` — file classification и image import transaction: decode/validate-all-before-mutate, empty-document sizing, drag/drop/file-input routing к image/PSD/project paths и tab-switch guard.
- `src/document/resize-command-controller.js` — canonical synchronous Image Size / Canvas Size transaction owner: captures the originating document, builds the complete resize/shift plan before mutation, revalidates exact active ownership immediately before publication, suppresses no-op history and runs geometry transient cleanup + one history publication + fit only for a real change. Core size/transform safety stays in `src/core/state.js`; Crop/pointer semantics stay outside this owner.
- `src/document/background-command-controller.js` — canonical synchronous Document Background transaction owner: delayed Apply carries the exact originating document object, revalidates it immediately before mutation, suppresses same-value history and publishes `Фон документа` once for a real change. Modal/options/status stay in `src/main.js`; background schema/rendering remain in core owners.
- `src/painting/controller.js` — единый владелец raster edit state: reusable Canvas8 buffer/context/layer id, native high-depth/CMYK paint buffer, paint-preview frame lifecycle/override, materialization и persistence.
- `src/painting/command-controller.js` — one-shot raster commands для fill, raster line и очистки пикселей текущего raster layer внутри активного выделения. Он получает target/selection/tool/transaction/UI через grouped ports; глобальные pointer events, selection state, history storage и multi-layer clipboard cut остаются вне него.
- `src/painting/gradient-command-controller.js` — persisted Gradient command owner: получает exact originating document из drag, использует shared `paintPersisting`, готовит selection-clipped Canvas, после async PNG encoding повторно проверяет object identity перед `addLayer`/history. Preview остаётся в `src/main.js`; подробный контракт — `docs/architecture/GRADIENT_COMMAND.md`.
- `src/painting/gesture-controller.js` — lifecycle одного brush/eraser/retouch stroke: target selection, native-vs-Canvas path, begin/move/end, preview scheduling и публикация результата через узкие grouped ports. `currentTool`, tool-specific dispatch, selection/history ownership и общий async edit guard остаются в `src/main.js`; generic capture/active-pointer routing вынесен в `src/interaction/pointer-lifecycle-router.js`.
- `src/retouch/controller.js` — destructive retouch boundary: clone/heal source и immutable stroke snapshots, smudge/blur/dodge/burn, private scratch state и native 16/32-bit/CMYK dispatch; общий raster edit buffer приходит из `src/painting/controller.js`, а stroke orchestration — из `src/painting/gesture-controller.js`.
- `src/core/*.js` — domain, render, pixel, history, IO, recovery и color logic.
- `src/document/psd-import-controller.js` — канонический owner PSD/PSB import transaction: file guard, decode orchestration, decoded layer/group/path mapping, high-depth/CMYK preservation, ICC-preview policy, stale-document guard и публикация через runtime port. Binary parser остаётся в `src/formats/psd.js`.
- `src/document/psd-import-semantics.js` — Photoshop-specific import semantics для Text/Shape/Adjustment/Smart Object и editable embedded assets. Stable core/domain contracts импортируются напрямую; browser decode/preview и shared vector-mask/opaque-resource bridges приходят явными ports. Session/history/publish и binary writer здесь не живут.
- `src/document/psd-native-metadata-plans.js` — канонический owner Photoshop-native export eligibility/rewrite planning для Text/TySh, solid Shape, Adjustment и Smart Object metadata; вызывает только публичные rewrite primitives формата и не пишет PSD/PSB layout.
- `src/document/psd-export-controller.js` — канонический owner document→PSD/PSB writer preparation: bounds, group lineage, native 16/32-bit/CMYK eligibility, raster/native payloads, merged composite and export warnings. Metadata plans импортируются напрямую из соседнего document owner; browser rendering и generic vector-mask bridge остаются узкими ports.
- `src/formats/psd.js` — канонический PSD/PSB binary codec и Photoshop metadata parse/write/rewrite-primitive boundary.
- `src/app.bundle.js` — generated artifact для `file://`; править только через `npm run build`.
- `src/adapters/psd.js` и `src/core/tool-layout.js` — legacy compatibility shims; implementation туда не возвращать.

## 3. Критические инварианты

1. **file:// first** — editor должен стартовать без dev-server.
2. **No destructive bypass** — lock, selection, Undo/Redo и pending async edit guards должны сохраняться.
3. **Precision ownership** — 16/32-bit и CMYK typed sources нельзя тихо сводить к Canvas8, если операция имеет native path.
4. **PSD/PSB honesty** — unsupported Photoshop semantics не выдавать за native round-trip; preserve bytes/metadata там, где контракт это обещает.
5. **Generated bundle parity** — source graph и `src/app.bundle.js` обязаны совпадать.
6. **Bounded memory/state** — safety limits и bounded caches/queues не снимать ради прохождения теста.
7. **Regression before suppression** — исправлять root cause, а не выключать проверки.

Более формальные границы: [architecture/BOUNDARIES.md](architecture/BOUNDARIES.md).
