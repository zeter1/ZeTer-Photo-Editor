## Repository gates

```bash
npm run build
npm test
npm run check
npm run test:browser
```

CI performs:
1. checkout + Node 24;
2. `npm run check`;
3. generated browser artifact parity: `git diff --exit-code -- src/app.bundle.js index.html version.json`;
4. real Chromium `file://` smoke;
5. `git diff --check`.

Do not weaken these gates to make a refactor pass.
