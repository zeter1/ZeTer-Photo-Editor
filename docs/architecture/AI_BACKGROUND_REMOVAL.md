# Brush-guided neural background removal

## Behavior and owners

`remove-background` / Shift+E uses approximate green foreground hints and red background/exclusion hints (Alt temporarily paints red). These are prompts, not a clipping mask. SAM 2.1 Tiny predicts the whole object; weak SlimSAM is no longer available in this tool. Alpha changes only on the captured RGB8 raster layer; other layers and transforms remain unchanged. Existing alpha never increases. One `Удалить фон` history entry; Undo/Redo, processing cancel and hint reset use established owners.

- `src/painting/object-removal-controller.js`: shared brush lifecycle, independent background instance, immutable layer-local mask values 1/2, per-stroke mark capture/rollback, green/red preview and opt-in transient stroke Undo/Redo. Completed changed strokes retain before-mask snapshots (at most 32 snapshots / 32 MiB across Undo and Redo); no-op/canceled strokes do not consume history or discard Redo. Reset, stale owner and successful inference clear both stacks. Exact document/layer/serial/transform/visibility/lock validity remains authoritative.
- `src/ai/background-models.js`: allowlisted quality model catalog (only SAM2), engine capture and legacy selected-model persistence at `zeter-background-removal-choice-v1`, only SAM 2.1 Tiny. A previously stored SlimSAM choice falls back to SAM2. `capture()` freezes the engine/model before asynchronous preparation. Switching selection never redirects pending processing. Legacy SlimSAM cache is neither read nor automatically deleted; no SlimSAM installation/selection is exposed.
- `src/ai/sam-preprocess.js`: distance-based interior seeds, up to three separated seeds per substantial region; up to four foreground/eight background regions and 24 total prompts. Accidental thin brush fringes are avoided. A small explicit separated mark of at least 16 pixels survives alongside a large body; smaller noise is ignored unless it is the sole region. Positive/negative labels must agree with a candidate before confidence ranking. The contour is never clipped to the brush.
- Postprocessing removes only unprompted foreground speckles <=16 model pixels and fills enclosed pinholes <=16 without an exclusion seed. Substantial disconnected parts, substantial openings and explicitly excluded holes survive. Confidence noise does not make the interior translucent. Optional feather 0–3 ORIGINAL pixels affects edges only. Neural resolution remains 256x256, so this is not full-resolution hair matting.
- `src/ai/sam-runtime.js`: one owned Blob worker, checked encoder/decoder contracts, local externalData for SAM2, int64 labels 0/1. Encoder released before decoder. No inference fetches; termination/cancel/180s timeout reuse `lama-runtime.js`. No stored photos/embeddings/prompts.
- `src/ai/sam-assets.js`: pinned size/SHA256 descriptors; verified downloader in `asset-cache.js`. SlimSAM DB `zeter-background-removal-model-v1` (5 fixed keys), SAM2 DB `zeter-background-sam2-model-v1` (7 fixed keys). Shared ORT bytes are independently stored; deleting one model or a canceled partial install does not delete another model, photos, recovery or projects.
- `src/painting/background-removal-command-controller.js`: capture model/feather before first await; shared raster persistence exclusion, repeated owner/stale/abort checks, RGB8 preparation, alpha-only publication, one history entry. High-depth/CMYK rejects without conversion; failure discards temporary buffer and retains hints.
- `src/ui/background-model-settings-controller.js`: SAM2 install/cancel/remove/progress card, cache-only startup, truthful cached/page-only readiness. LaMa retains its separate card. Parent dialog/tabs/processing settings remain in `editor-settings-controller.js`; toolbar/tool-help/pointers stay in `main.js`.
- `tools/build-bundle.mjs`: explicitly includes the catalog and model modules. Never edit generated `app.bundle.js` manually.

## Hint history and image edges

In background-brush mode the main Undo/Redo dispatch (keyboard/menu/buttons) prefers hint history, then delegates to the canonical document history owner. Ctrl+Z during drawing rolls back the active stroke and releases its pointer capture. Busy inference blocks both routes. After inference, Ctrl+Z restores the photo as usual. Hints remain transient and never change photo bytes.

The pointer lifecycle router listens on the stage viewport while the overlay canvas exclusively owns capture. Main dispatch admits outside hover/down only for background-brush blank stage surfaces, without stealing input controls or other tools. Background coordinates stay unclamped; layer-local mask painting and canvas drawing clip to image bounds. Starting a stroke focuses the viewport with preventScroll so Ctrl+Z is not swallowed by the size field. The selected-layer transform supplies cursor scaling/rotation even outside the image. Outside the image the native arrow is visible, including during pointer capture; inside the selected image only the brush ring is shown. The viewport blank surface uses cursor:default, while main pointer dispatch updates the overlay cursor from the unclamped point and selected-layer geometry. The selected-layer frame keeps its controls but no longer draws a name badge over the image.

## Pinned contracts and preprocessing

Historical diagnostic/compatibility path, not offered to users: SlimSAM: Xenova/slimsam-77-uniform revision `5850ab45f587c112167512ffef949107115e26a0`, q8 encoder 8,882,165 bytes and decoder 4,903,810 bytes; model + ORT ~39 MiB. Encoder `pixel_values` float32 [1,3,1024,1024] returns `image_embeddings` and `image_positional_embeddings` [1,256,64,64]. Decoder consumes these, `input_points` float32 [1,1,N,2], `input_labels` int64 [1,1,N]. Resize longest edge to 1024, zero pad AFTER ImageNet normalization. Points follow actual resized dimensions. No boxes/previous mask.

SAM 2.1 Hiera Tiny: onnx-community/sam2.1-hiera-tiny-ONNX revision `814a066640debee5a91e70aa401fb8e17e030503`, q8 encoder with external data and float32 prompt decoder with external data; model 74,185,577 bytes, model + ORT 101,086,965 bytes (~97 MiB). Encoder same pixel input, outputs `image_embeddings.0` [1,32,256,256], `.1` [1,64,128,128], `.2` [1,256,64,64]. Decoder consumes all three, points/labels and empty float32 `input_boxes` [1,0,4]. Input is stretched to square 1024x1024, without padding; points scale independently by width/height. Checked local externalData paths: `vision_encoder_quantized.onnx_data`, `prompt_encoder_mask_decoder.onnx_data`. No previous-mask input.

Both use mean [.485,.456,.406], std [.229,.224,.225], transparent input composited on white. Both output float32 logits `pred_masks` [1,1,3,256,256] and `iou_scores` [1,1,3]. SAM2 also outputs `object_score_logits`; it is not used for confidence ranking. Graph supplies the point half-pixel offset. Attribution/primary sources: [../THIRD_PARTY_AI.md](../THIRD_PARTY_AI.md).

## Installation, limits and guidance

Explicit SAM2 install is available in settings, rich tool help and persistent notice. Cache-only startup never downloads automatically. Separate SAM2 and LaMa cards make one model/installation clear. Remove is allowed after canceled/partial installs and deletes only fixed model keys. Browser storage quota still reserves space for recovery; other tabs may retain resident model bytes. Models cannot be removed during their own install/inference.

RGB8 raster <=8 million pixels. Roughly mark several areas of the WHOLE object, not just a door/face; mark unwanted adjacent objects/background red. If a paw/tail is missing, Undo and add a green mark there. SAM2 is the only offered background model after the user requested removal of weak alternatives. Neither model guarantees perfect boundaries; small hair, translucent glass, contact shadows and occlusion remain limits. Feather does not infer new details.

## Evidence and verification

Nearest tests: `tests/background-removal.test.mjs`, `tests/background-quality.test.mjs`, shared object-removal regressions, `tests/background-hint-history.test.mjs`, pointer/router/history/surface regressions. Canonical `npm run check` and `npm run test:browser`; native file:// smoke required in addition to module tests.

A broad Mustang mask reconstructed approximately from the supplied screenshot made the former edge sampler choose road positives. Eight contaminated points produced 1767 hole pixels/577 hole components in the selected SlimSAM 256 mask. Correct interior seeds substantially improved the body. Exact original transient brush mask was not available; reconstruction is diagnostic evidence, not ground-truth annotation. Float32 decoder alone did not fix contaminated prompts; quantization as root cause was not established.

Real CPU Chrome corpus: Mustang, public SAM truck, official HF SAM2 dog/groceries fixtures and COCO cats. Known object/background alpha probes plus unchanged RGB/alpha bound were checked; touching bags and two cats used red exclusion marks, whole truck used a broad body stroke, cat paw/tail used extra green marks. Initial single-door hint selected just the door on both models; this was retained as a failed first attempt, then corrected by marking the whole target. Initial cat probe [195,320] was on the couch; corrected to tail [185,304]. These are semantic samples plus visual review, not pixel ground-truth IoU or a hair-quality benchmark. SlimSAM still failed ear/background cases; keep this limitation explicit.

Native UI acceptance: install/cancel/partial cleanup, real ONNX worker with verified downloaded bytes, green/red preview without photo mutation, processing cancel, other-layer byte identity, exact PNG Undo/Redo, deletion isolation and cached offline reload. Artifact responses can be replayed from already downloaded/hash-verified bytes in isolated test contexts; this proves loader/worker/UI, not current remote availability. WebGPU and arbitrary-image quality remain NOT VERIFIED.
